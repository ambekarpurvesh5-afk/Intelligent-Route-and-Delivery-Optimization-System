Data Structures & Algorithms (DSA) Viva Guide

1. Problem Formalization: Capacitated VRP with Precedence (PD-VRP)

The system addresses the Vehicle Routing Problem with Pickups and Deliveries (VRPPD). A set of delivery orders $O = \{o_1, o_2, \dots, o_m\}$ must be assigned to fleet vehicles $V = \{v_1, \dots, v_k\}$ such that:

  • Precedence Constraint: For every order $o_i$, the pickup node must strictly precede the dropoff node in the vehicle's sequence: $\text{pos}(\text{pickup}_i) < \text{pos}(\text{dropoff}_i)$.
  • Capacity Constraint: The instantaneous payload at any point in the route never exceeds the vehicle capacity: $L(t) \le C_v$.
  • Priority Scheduling: Urgent orders are served with prioritized distance weighting in tour construction.
  • VRP Complexity: VRP is known to be NP-Hard (generalization of the Traveling Salesperson Problem). Exact algorithms have $O(n!)$ factorial complexity, requiring polynomial-time heuristics (Nearest Neighbor + 2-Opt) for practical urban routing.

3. Dijkstra's Algorithm vs A* Search Comparison

Attribute Dijkstra's Algorithm A* Search
Evaluation Function $f(n) = g(n)$ (cost from start) $f(n) = g(n) + h(n)$ (cost + heuristic)
Heuristic $h(n)$ None (uninformed blind radial search) Haversine great-circle distance (admissible & consistent)
Time Complexity $O((V + E) \log V)$ $O((V + E) \log V)$ worst case, orders of magnitude fewer visited nodes in practice
Admissibility Guarantee Always finds optimal shortest path Guaranteed optimal because $h(n) \le h^*(n)$ (straight-line distance is always $\le$ actual road distance)

4. Heuristic Optimization: 2-Opt Local Search

2-Opt is a local search algorithm that iteratively tests exchanging pairs of edges $(u_i, u_{i+1})$ and $(u_j, u_{j+1})$ with $(u_i, u_j)$ and $(u_{i+1}, u_{j+1})$ by reversing the intermediate sequence. This eliminates route self-crossings and zigzag detours while strictly enforcing precedence rules, reducing fleet mileage by 25% – 65% compared to naive FIFO routing.
